# PRD: 할 일 관리 앱
## 1. Why - 목적

일일 할 일을 상위 목표(주간 계획, 1년 목표)와 연결하여 실행과 목표 간 정렬을 확보
할 일 상태를 시각적으로 관리하여 진행 상황을 직관적으로 파악
주간 단위 목표 달성률을 자동 산출하여 계획 대비 실행 격차를 가시화
---
## 2. Who - 타깃 사용자

개인 목표(학습, 커리어, 습관)를 체계적으로 관리하고 싶은 개인 사용자
일일 업무를 상위 계획과 연결해 관리하고 싶은 직장인/1인 지식노동자
칸반 스타일의 직관적 상태 관리를 선호하는 사용자
---

3. User Flow

1년 목표 생성 → 주간 계획 생성 및 1년 목표에 연결 → 할 일 생성 및 주간 계획에 연결
할 일 목록 확인 → 할 일 상태(todo/doing/done) 드래그 앤 드롭으로 변경
할 일 상태 변경 시 → 연결된 주간 계획의 진행률 자동 갱신
주간 계획 진행률 확인 → 1년 목표 대시보드에서 하위 주간 계획 진행 현황 확인
할 일 수정/삭제 → 목록 및 연결된 상위 계획에 즉시 반영
---

4. 기능 요구사항

P0 - 핵심 기능
할 일 생성/조회/수정/삭제(CRUD)
할 일 상태 관리: todo / doing / done
할 일 상태를 드래그 앤 드롭으로 변경하는 칸반 보드 UI
기간 구조 생성 및 관리: 일일 할 일 / 주간 계획 / 1년 목표
구조 연결: 할 일 → 주간 계획 → 1년 목표 (상위-하위 관계 설정)
주간 계획 진행률 자동 계산 (완료된 할 일 수 / 전체 할 일 수 기준)
진행률 실시간 반영: 할 일 상태 변경 시 주간 계획 진행률 즉시 갱신

P1 - 추가 기능
1년 목표 단위 진행률 대시보드 (하위 주간 계획 진행률 집계)
할 일 우선순위 설정
할 일 마감일/알림 설정
주간 계획 자동 생성 템플릿 (반복 일정 기반)
완료율 통계 리포트(일간/주간/월간 추이)
할 일 검색 및 필터(상태별, 기간별, 태그별)
